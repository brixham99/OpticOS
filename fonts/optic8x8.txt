# OpticOS 8x8 font — clean-room original artwork
# ============================================================
# 96 glyphs, codes 32-127, for the planned 32-column text mode.
#
# This file is the source of truth. Every bitmap was drawn by
# hand in '#' (ink) and '.' (paper). It was not copied from the
# Sinclair ROM font, from any other copyrighted font, or by
# scaling the OpticOS 4x8 font. The character *set* (which codes
# exist) matches the 4x8 font:
#   - standard ASCII 32-126
#   - code 96 is grave / backtick, not a pound sterling
#   - code 127 is a solid editor cursor / wrap block
#   - there is no copyright glyph; banners use ASCII (c)
#
# Metrics (Spectrum-friendly, ULA / composite in mind):
#   - 8 x 8 cell
#   - column 0 is a 1-pixel left bearing (empty), except code 127
#   - column 7 is a right bearing for most glyphs; M, W, m, w
#     and a few wide signs may use it
#   - Shared baseline at row 5. Caps and digits occupy rows 0-5.
#   - Lower case has a 5-row x-height on rows 1-5; ascenders also
#     use row 0; descenders (g j p q y) use rows 6-7.
#   - vertical stems are 2 pixels wide (favoured by the ULA)
#   - horizontal strokes are 1 pixel, so they balance the stems
#     after TV / composite bloom
#
# Style: geometric, open counters, consistent weight. A small
# nod to the Optica brand in the octagonal / aperture-like O
# and C, and in the clean technical construction. Distinct 0
# (rectangular, slashed) vs O (octagon, no slash); I / 1 / l / |
# are all different. 8 is symmetric (both bowls the same width
# and aligned, waist by indenting the middle). A has a tall
# pointed roof and a low crossbar, so it does not read as H.
# D has a square left side and a rounded right.
#
# Each glyph is a header line
#   U+XXXX (code) name
# followed by exactly 8 rows of 8 characters.

# OpticOS / OpticBASIC user manual

- **[OpticOS_User_Manual.pdf](OpticOS_User_Manual.pdf)**: A5, 72 pages, British English (edition 6).
- `manual.md` is the source, `template.html` the page design: Inter for text and JetBrains Mono for code and screen output (both SIL OFL, embedded from the static subsets and licences in `fonts/`), Nathan's artwork (`cover.jpg`) as the full-bleed front cover, the title page with the Optica logo, and the logo in the page headers. `python3 build.py` writes `manual.html` and the PDF with headless Chrome, in two passes so that the contents page gets its page numbers.
- `examples/*.bas` are the worked examples in chapter 13 and the Happy Bat game in chapter 14. `python3 verify.py` types each into the ROM in the test rig, runs it and lists it; `examples/verified_output.txt` is its output for this edition. The last one, Happy Bat, is a game with its own chapter: `hbloader.bas` (its machine code as type-in DATA lines with check numbers) runs first, then `happybat.bas` is run to its title screen and stopped with BREAK. `examples/happybat.asm` is the machine code source, printed in full at the end of chapter 14.
- The Happy Bat screenshots (`img/run_happybat_*.png`) were taken in Fuse with the v1.0.1 ROM by the tools in [brixham99/happy-bat](https://github.com/brixham99/happy-bat); the manual shows the title and play screens.
- The recursive tree screenshot (`img/run_tree.png`, chapters 9 and 13) was retaken in Fuse with the v1.0.3 ROM for edition 6.
- `fuse_shots.py` types the examples into real Fuse (tape traps off) and takes the screenshots in `img/`. The game screenshots and the editing screenshot come from the phase 1 and phase 4 reports.
- `preview/` has PNGs of the cover and one reference page.
- `print/` is the A5 print edition (ring bound, double-sided): the cover with 3 mm bleed and the interior pages with a binding gutter, made by `python3 build_print.py` (see `print/README.md`). The Inter subsets in `fonts/` include Latin Extended-A, so names such as Vicențiu Iordăchescu print in Inter.
